Keyword search and semantic search

Keyword search

Find exact words or character sequences. Useful for known terms, identifiers, and values.

Semantic Search

Find conceptually related content. Useful when you know the idea but not the document’s exact wording.

Semantic Search complements exact matching. Use it to locate a requirement, a description of behavior, or a policy provision, then read the original passage to confirm the details.
