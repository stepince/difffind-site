Compare Two XML Files and Find Every Change

Paste two versions of an XML document, or load them from files, a URL or a cURL command, and DiffFind compares the parsed structure. Added, removed and changed elements, attributes and text values are easy to find without reading markup line by line. Add optional AI analysis to understand what a change means.

What the comparison finds

  • Added and removed elements, including nested ones.
  • Attribute changes: values that changed, and attributes that were added or removed.
  • Text-value changes inside elements.
  • Structural differences, because the parsed structure is compared rather than raw lines.
  • Formatting-only differences: indentation and line breaks between elements are not reported as changes.

DiffFind compares well-formed XML. It does not validate against a schema or repair malformed markup.

Example: an order before and after

An illustrative before-and-after example.

Before

<order id="1042" status="pending">
  <customer>Acme Ltd</customer>
  <item sku="A-100" qty="2">
    <price currency="USD">19.99</price>
  </item>
</order>

After

<order id="1042" status="shipped">
  <customer>Acme Ltd</customer>
  <item sku="A-100" qty="3">
    <price currency="USD">24.99</price>
  </item>
  <shipping>express</shipping>
</order>

What the comparison reports

  • The status attribute of order changed from pending to shipped.
  • The qty attribute of item changed from 2 to 3.
  • The price text changed from 19.99 to 24.99.
  • A new shipping element was added.

Frequently asked questions

How do I compare two XML files?

Paste both XML documents, load them from files, or bring them in from a URL or cURL command. Then run the comparison to see the added, removed and changed elements and values.

Can DiffFind identify XML attribute changes?

Yes. Attributes are part of the compared structure, so a changed, added or removed attribute is reported along with element and text changes.

Does DiffFind detect structural XML differences?

Yes. DiffFind compares the parsed structure of the XML, so added and removed elements are reported, not just changed text.

Does DiffFind validate XML against a schema?

No. DiffFind compares well-formed XML. It does not validate against a schema or repair malformed markup.

Is AI required for XML comparison?

No. The exact comparison works without AI. Semantic analysis is optional.
