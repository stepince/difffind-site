DIFFFIND EXTENSION

DiffFind Launcher — Open DiffFind in One Click

DiffFind Launcher is a Chrome extension that opens DiffFind in a dedicated, app-style window from your toolbar, or takes you back to the one you already have open. No account and no tracking. Requires Chrome 102 or later.

Add to Chrome ↗

How to install and use it

  1. 01

    Install from the Chrome Web Store.

    Add DiffFind Launcher to Chrome from its Chrome Web Store page.

  2. 02

    Click the DiffFind icon.

    Find the DiffFind icon in the Chrome toolbar (pin it from the puzzle-piece menu if you don’t see it) and select Open DiffFind.

  3. 03

    Work in a focused window.

    DiffFind opens in its own app-style window. Click the icon again any time to return to it.

What the extension does

  • One-click toolbar access to DiffFind.
  • Opens DiffFind in a separate, focused app-style window.
  • Relaunching restores and focuses your existing window instead of opening duplicates, with your current comparison left as it was.
  • Lets you set your own DiffFind address for a custom or self-hosted instance, with a one-click reset to the default.
  • No account, no tracking, and only one permission (storage).

Using it with a self-hosted DiffFind

If you run your own DiffFind instance, point the launcher at it:

  1. Click the DiffFind icon in the toolbar.
  2. Click Configure in the popup to open the launcher settings.
  3. Enter the http or https URL of your instance, for example https://difffind.example.com.
  4. Click Save. Click Reset to return to https://app.difffind.com.

A window that is already open keeps its current page; the new address is used the next time a window is opened.

Learn more about self-hosted DiffFind.

Permissions and privacy

The extension is only a launcher: it opens DiffFind and does not compare anything itself. It requests a single permission, storage, to remember your DiffFind window for the current browser session and the site URL you configure. It does not read page content, browsing history, documents, or AI-provider keys, runs no analytics, and does not send anything anywhere. What you compare in DiffFind is covered by the DiffFind privacy policy.

Requirements and limitations

  • Chrome 102 or later.
  • An internet connection and access to your DiffFind site are required; navigation errors appear in the DiffFind window.
  • The extension tracks the window it opened. A DiffFind tab you opened manually is not adopted.
  • After restarting the browser, or reloading, updating, or re-enabling the extension, close any old DiffFind window before launching again to avoid a second window.

Common questions

Frequently asked
questions.

What does the DiffFind Launcher extension do?

It adds a DiffFind button to your Chrome toolbar. One click on Open DiffFind opens DiffFind in a dedicated, app-style window, or returns you to the DiffFind window you already have open.

Does the extension need an account or special permissions?

No account is needed. The extension requests only Chrome’s storage permission, which it uses to remember your DiffFind window for the current browser session and the site URL you configure. It does not read page content, browsing history, documents, or AI-provider keys, and it includes no analytics.

Will it open a new window every time I click?

No. If your DiffFind window is already open, the next launch restores it if minimized and brings it to the front without reloading it, so your current comparison stays as you left it. If you closed it, the next launch opens a fresh one.

Can I use it with a self-hosted DiffFind?

Yes. Click Configure in the popup, enter the http or https URL of your DiffFind instance, and click Save. Reset returns to the default, https://app.difffind.com.

Is the extension a separate comparison tool?

No. It is a launcher. Comparisons run in the DiffFind web application, either the hosted version or your own instance, so an internet connection to that site is required.

Which version of Chrome do I need?

Chrome 102 or later.
