When to search a document by meaning

Use it to find a payment term, a termination clause, an obligation, or a described behavior when you know the idea but not the document’s wording. Searching both versions of a document lets you see how the answer to the same question changed.

Semantic search points you to relevant passages. Read the original text to confirm the details before relying on them.
