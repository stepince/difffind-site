What you get

DiffFind Free

Free indefinitely

  • Basic lexical comparison.
  • No expiry and no account needed.

DiffFind Pro Trial

90 days free

  • Semantic comparison.
  • AI-powered analysis (bring your own provider API key).
  • Advanced comparison features.

The 90-day trial starts the first time you launch the app. When it ends, you keep access to the Free features. Your documents, history, and settings are not deleted.

Before you install

  • DiffFind Desktop runs on your computer; no account is needed for the Free tier or the trial.
  • Early builds may not be code-signed yet, so macOS or Windows may show a warning on first launch. Download only from this page or the DiffFind release page, and check the SHA256 checksum published with each release.
  • AI analysis is optional and uses your own provider API key.

Prefer the browser? Launch the web app. Learn more on the DiffFind Desktop page.
