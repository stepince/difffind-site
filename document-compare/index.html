DIFFFIND FEATURES

Document Comparison — See What Changed Between Versions

Load the original and the revised version of a document and see exactly what changed. DiffFind highlights additions, removals, and edits, so you can review a revision without reading both copies side by side.

Try DiffFind

How it works

01

Load both versions.

Choose the original and the revised document, or paste the text of each.

02

Run the comparison.

DiffFind finds every difference between the two versions.

03

Review the changes.

See changed, added, and removed content highlighted, then check each one against the source.

Pick the comparison that fits your document

PDFs

Load two local PDFs and see changes highlighted on the page. See PDF Comparison.

Word documents

Compare two DOCX files as formatted text, with changes highlighted in the document. See Word Comparison.

Spreadsheets

Compare Excel workbooks (XLS and XLSX), every sheet at once. See Excel Comparison.

Plain text

Paste two versions and compare by character, word, sentence, line, or paragraph. See Text Compare.

Structured data

Compare the structure of JSON, YAML, XML, and CSV files instead of raw lines.

Have a document in another format? Copy its text and paste it into the text comparison.
