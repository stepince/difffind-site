Use YAML comparison to review deployment manifests, CI pipelines, application settings, and infrastructure files before they ship.

Example: a Kubernetes Deployment before and after

An illustrative before-and-after example of a Kubernetes Deployment manifest.

Before

apiVersion: apps/v1
kind: Deployment
metadata:
  name: web
spec:
  replicas: 2
  template:
    spec:
      containers:
        - name: web
          image: registry.example.com/web:1.4.0
          env:
            - name: LOG_LEVEL
              value: info
          resources:
            limits:
              memory: 256Mi
              cpu: 250m

After

apiVersion: apps/v1
kind: Deployment
metadata:
  name: web
spec:
  replicas: 4
  template:
    spec:
      containers:
        - name: web
          image: registry.example.com/web:1.5.2
          env:
            - name: LOG_LEVEL
              value: debug
            - name: FEATURE_CHECKOUT_V2
              value: "true"
          resources:
            limits:
              memory: 512Mi

What the comparison reports

  • The container image changed from web:1.4.0 to web:1.5.2.
  • replicas changed from 2 to 4.
  • The LOG_LEVEL environment variable changed from info to debug.
  • A new environment variable, FEATURE_CHECKOUT_V2, was added.
  • The memory limit changed from 256Mi to 512Mi, and the cpu limit was removed.

Frequently asked questions

How do I compare two YAML files?

Paste both YAML files, load them from files, or bring them in from a URL or cURL command. Then run the comparison to see the added, removed and changed values.

Can DiffFind compare Kubernetes YAML manifests?

Yes. Paste or load the two versions of a manifest, such as a Deployment, and review the changed image tags, replica counts, environment variables and resource limits.

How can I identify YAML configuration changes?

Run the comparison and read the list of changes. Every added key, removed entry and changed value is reported, which makes it easier to review a configuration change before it is applied.

Can I compare YAML files online?

Yes. Paste two YAML files into the quick compare on this page, or open DiffFind directly, and run the comparison in your browser.

Can I compare Docker Compose configurations?

Yes. A Docker Compose file is a YAML file, so paste or load two versions of it and compare them the same way. The same applies to CI pipeline definitions and other YAML configuration.
