RECURSOS DO DiffFind

Compare dois arquivos XML e encontre todas as alterações

Cole duas versões de um documento XML, ou carregue-as de arquivos, de uma URL ou de um comando cURL, e o DiffFind compara a estrutura interpretada. Elementos, atributos e valores de texto adicionados, removidos e alterados ficam fáceis de encontrar sem ler a marcação linha por linha. Adicione a análise opcional com IA para entender o que uma alteração significa.

Comparar arquivos XML

Como comparar arquivos XML

  1. 01

    Adicione os seus dois documentos XML.

    Cole-os, carregue um arquivo ou traga-os de uma URL ou de um comando cURL.

  2. 02

    Compare a estrutura.

    Detecte o formato automaticamente ou escolha XML e execute a comparação.

  3. 03

    Revise cada alteração.

    Inspecione elementos, atributos e valores adicionados, removidos e modificados. Se quiser, adicione a análise semântica com IA.

Experimente uma comparação rápida de XML

Seu texto só é enviado ao aplicativo DiffFind quando você clica em Encontrar diferenças. Nada é armazenado nesta página. O aplicativo está disponível, por enquanto, apenas em inglês.

O que a comparação encontra

  • Elementos adicionados e removidos, inclusive os aninhados.
  • Alterações de atributos: valores que mudaram e atributos que foram adicionados ou removidos.
  • Alterações de valores de texto dentro dos elementos.
  • Diferenças estruturais, porque a estrutura interpretada é comparada, e não as linhas brutas.
  • Diferenças apenas de formatação: indentação e quebras de linha entre elementos não são informadas como alterações.

O DiffFind compara XML bem formado. Ele não valida o XML com base em um esquema nem corrige marcação malformada.

Exemplo: um pedido antes e depois

Um exemplo ilustrativo de antes e depois.

Antes

<order id="1042" status="pending">
  <customer>Acme Ltd</customer>
  <item sku="A-100" qty="2">
    <price currency="USD">19.99</price>
  </item>
</order>

Depois

<order id="1042" status="shipped">
  <customer>Acme Ltd</customer>
  <item sku="A-100" qty="3">
    <price currency="USD">24.99</price>
  </item>
  <shipping>express</shipping>
</order>

O que a comparação informa

  • O atributo status de order mudou de pending para shipped.
  • O atributo qty de item mudou de 2 para 3.
  • O texto de price mudou de 19.99 para 24.99.
  • Um novo elemento shipping foi adicionado.

Perguntas frequentes

Como comparo dois arquivos XML?

Cole os dois documentos XML, carregue-os de arquivos ou traga-os de uma URL ou de um comando cURL. Em seguida, execute a comparação para ver os elementos e valores adicionados, removidos e alterados.

O DiffFind consegue identificar alterações em atributos XML?

Sim. Os atributos fazem parte da estrutura comparada; assim, um atributo alterado, adicionado ou removido é informado junto com as alterações de elementos e de texto.

O DiffFind detecta diferenças estruturais em XML?

Sim. O DiffFind compara a estrutura interpretada do XML; por isso, elementos adicionados e removidos são informados, e não apenas o texto alterado.

O DiffFind valida o XML com base em um esquema?

Não. O DiffFind compara XML bem formado. Ele não valida o XML com base em um esquema nem corrige marcação malformada.

A IA é necessária para comparar XML?

Não. A comparação exata funciona sem IA. A análise semântica é opcional.

Ferramentas relacionadas
