Respuestas rápidas sobre privacidad, formatos,
análisis con IA y la API.

¿Qué es la comparación de documentos con IA?

La comparación de documentos con IA encuentra las diferencias exactas entre dos versiones de un documento y luego te ayuda a entender si también cambió el significado. DiffFind combina una comparación determinista y repetible que muestra qué cambió con un análisis semántico opcional con IA que ayuda a explicar qué significa. Consulta la comparación de documentos y el diff semántico.

¿Puede DiffFind comparar solicitudes y respuestas de API?

Sí. Carga dos URL o dos comandos cURL para comparar respuestas de API, o pega cargas útiles JSON, YAML o XML para comparar solicitudes y respuestas de API por ruta. También puedes automatizar las comparaciones mediante la API REST de DiffFind. Consulta la comparación de API, la herramienta de comparación de cURL y la comparación de URL.

¿Qué es Semantic Find?

Semantic Find te permite buscar en los documentos por significado, no solo por las palabras exactas. Entiende la intención de tu búsqueda y puede localizar pasajes relevantes aunque el documento use una terminología distinta. Consulta la búsqueda semántica y la búsqueda semántica en documentos.

¿DiffFind guarda mis archivos?

No de forma predeterminada. El texto que introduces en esta página se envía a la aplicación DiffFind solo cuando haces clic en Encontrar diferencias, y no se guarda nada en esta página. En la aplicación, el contenido enviado para comparar se procesa para devolver un resultado y no se conserva más allá de lo necesario para ello, salvo que decidas guardarlo, por ejemplo el historial de comparaciones almacenado en tu navegador. Consulta la política de privacidad (en inglés).

¿Qué formatos de archivo admite DiffFind?

DiffFind compara texto sin formato, JSON, YAML, XML, CSV, PDF, hojas de cálculo de Excel (XLS y XLSX) y documentos de Word (DOCX). También puedes cargar contenido desde una URL o un comando cURL.

¿Qué hace el análisis semántico?

El análisis semántico es un análisis de significado opcional basado en IA. Resalta los cambios relevantes y explica su probable impacto. Los datos citados se contrastan con tus documentos de origen y se muestra el estado de verificación.

¿Necesito IA para comparar documentos?

No. La comparación básica es coherente y repetible, y funciona sin IA. El análisis semántico es una capa opcional que puedes añadir cuando quieras entender qué significa un cambio.

¿Qué nivel de detalle puede tener una comparación?

Puedes comparar por carácter, palabra, oración, línea o párrafo, y ver las adiciones, las eliminaciones y el texto movido junto con el contexto que los rodea.

¿Cómo llamo a la API de DiffFind?

Envía una solicitud POST a /v1/compare con tu contenido anterior y posterior (los campos before y after). El formato completo de la solicitud se describe en la especificación OpenAPI en app.difffind.com/openapi.json.
