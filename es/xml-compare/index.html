FUNCIONES DE DiffFind

Compara dos archivos XML y encuentra todos los cambios

Pega dos versiones de un documento XML, o cárgalas desde archivos, una URL o un comando cURL, y DiffFind compara la estructura analizada. Los elementos, atributos y valores de texto añadidos, eliminados y modificados son fáciles de encontrar sin leer el marcado línea por línea. Añade un análisis opcional con IA para entender qué significa un cambio.

Comparar archivos XML

Cómo comparar archivos XML

  1. 01

    Añade tus dos documentos XML.

    Pégalos, carga un archivo o tráelos desde una URL o un comando cURL.

  2. 02

    Compara la estructura.

    Detecta el formato automáticamente o elige XML y ejecuta la comparación.

  3. 03

    Revisa cada cambio.

    Inspecciona los elementos, atributos y valores añadidos, eliminados y modificados. Si quieres, añade un análisis semántico con IA.

Prueba una comparación rápida de XML

Tu texto se envía a la aplicación DiffFind solo cuando haces clic en Encontrar diferencias. No se guarda nada en esta página. La aplicación está disponible por ahora solo en inglés.

Qué encuentra la comparación

  • Elementos añadidos y eliminados, incluidos los anidados.
  • Cambios en los atributos: valores que cambiaron y atributos que se añadieron o eliminaron.
  • Cambios en los valores de texto dentro de los elementos.
  • Diferencias estructurales, porque se compara la estructura analizada y no las líneas en bruto.
  • Diferencias solo de formato: la sangría y los saltos de línea entre elementos no se notifican como cambios.

DiffFind compara XML bien formado. No lo valida contra un esquema ni repara el marcado mal formado.

Ejemplo: un pedido antes y después

Un ejemplo ilustrativo de antes y después.

Antes

<order id="1042" status="pending">
  <customer>Acme Ltd</customer>
  <item sku="A-100" qty="2">
    <price currency="USD">19.99</price>
  </item>
</order>

Después

<order id="1042" status="shipped">
  <customer>Acme Ltd</customer>
  <item sku="A-100" qty="3">
    <price currency="USD">24.99</price>
  </item>
  <shipping>express</shipping>
</order>

Qué informa la comparación

  • El atributo status de order cambió de pending a shipped.
  • El atributo qty de item cambió de 2 a 3.
  • El texto de price cambió de 19.99 a 24.99.
  • Se añadió un nuevo elemento shipping.

Usa Cargar ejemplo más arriba para probar una comparación similar. El análisis semántico opcional puede describir el impacto, mientras que la lista exacta de arriba sigue siendo la fuente de verdad.

Preguntas frecuentes

¿Cómo comparo dos archivos XML?

Pega ambos documentos XML, cárgalos desde archivos o tráelos desde una URL o un comando cURL. Después ejecuta la comparación para ver los elementos y valores añadidos, eliminados y modificados.

¿Puede DiffFind identificar los cambios en los atributos XML?

Sí. Los atributos forman parte de la estructura comparada, así que un atributo modificado, añadido o eliminado se notifica junto con los cambios de elementos y de texto.

¿Detecta DiffFind las diferencias estructurales en XML?

Sí. DiffFind compara la estructura analizada del XML, de modo que se notifican los elementos añadidos y eliminados, no solo el texto modificado.

¿Valida DiffFind el XML contra un esquema?

No. DiffFind compara XML bien formado. No lo valida contra un esquema ni repara el marcado mal formado.

¿Es necesaria la IA para comparar XML?

No. La comparación exacta funciona sin IA. El análisis semántico es opcional.

Herramientas relacionadas

Para la automatización, consulta Comparar API. Para comparar respuestas XML de solicitudes reales, compara respuestas de cURL o compara dos URL. Para juzgar si un cambio es relevante, usa el diff semántico.
