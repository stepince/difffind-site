FUNCIONES DE DiffFind

Compara dos URL y descubre qué cambió

Introduce dos URL y DiffFind carga el contenido de cada dirección y luego muestra exactamente qué cambió. Úsalo para comparar endpoints de API, páginas web y otro contenido alojado basado en texto, como un endpoint de staging y uno de producción, o la misma dirección antes y después de un lanzamiento. ¿Necesitas un método, encabezados o un cuerpo de solicitud? Usa en su lugar la comparación de cURL.

Comparar dos URL

Cómo comparar dos URL

  1. 01

    Introduce o pega ambas URL.

    Elige URL como tipo de entrada e introduce una dirección para el lado Antes y otra para el lado Después.

  2. 02

    Carga y revisa las diferencias exactas.

    DiffFind carga el contenido de cada dirección. La comparación léxica muestra cada adición, eliminación y valor modificado.

  3. 03

    Si quieres, añade un análisis semántico con IA.

    Pide una explicación de qué significan los cambios. La comparación exacta sigue siendo la fuente de verdad.

Prueba una comparación rápida de URL

Tus URL se envían a la aplicación DiffFind solo cuando haces clic en Cargar y comparar. La aplicación obtiene ambas direcciones y compara las respuestas. No se guarda nada en esta página. La aplicación está disponible por ahora solo en inglés.

Qué puedes comparar con dos URL

DiffFind carga el contenido de texto que devuelve cada URL, así que puedes comparar:

  • Endpoints de API, como la respuesta JSON de un servicio de staging y de uno de producción.
  • Páginas web, comparando el contenido que devuelve la dirección.
  • Contenido alojado basado en texto, como feeds XML, archivos de configuración y documentos de texto sin formato.

La dirección debe ser una que la aplicación DiffFind pueda cargar. Si una solicitud necesita credenciales o un método concreto, ponla en un comando cURL y usa la comparación de cURL.

Ejemplo: staging frente a producción

Este ejemplo ilustrativo compara el endpoint de estado de un servicio en dos entornos. Las URL usan el dominio reservado example.com y las respuestas están simplificadas.

Antes (staging)

https://staging.example.com/api/status

{
  "version": "2.4.1",
  "status": "ok",
  "featureFlags": {
    "newCheckout": true
  }
}

Después (producción)

https://www.example.com/api/status

{
  "version": "2.4.0",
  "status": "ok",
  "featureFlags": {
    "newCheckout": false
  }
}

Qué informa la comparación

  • version cambió de "2.4.1" a "2.4.0".
  • featureFlags.newCheckout cambió de true a false.
  • status no ha cambiado.

El análisis semántico opcional puede describir después el impacto, por ejemplo, que una función habilitada en staging todavía no está habilitada en producción. Usa Cargar ejemplo en el formulario de arriba para probar la comparación con una API de pruebas pública.

Comparación de URL y comparación de cURL

La comparación de URL usa dos direcciones. Es la forma más rápida de comparar lo que devuelve cada dirección.

La comparación de cURL admite definiciones completas de solicitudes HTTP: un método como POST o PUT, encabezados y un cuerpo de solicitud. Úsala cuando las dos solicitudes se diferencian en algo más que la dirección. Consulta cómo comparar respuestas de cURL.

Primero las diferencias exactas, después el significado

La comparación léxica identifica las adiciones, las eliminaciones y los valores modificados exactos, y es determinista. El análisis semántico opcional la complementa explicando qué significan los cambios. Nunca se necesita IA para comparar dos URL.

Casos de uso habituales

  • Comparar endpoints de staging y de producción.
  • Comprobar una dirección antes y después de un lanzamiento.
  • Comparar la respuesta de una API entre dos versiones de un servicio.
  • Revisar los cambios en una configuración o un feed alojados.
  • Comparar respuestas estructuradas con Comparar JSON o Comparar XML cuando ya tienes los datos.

Preguntas frecuentes

¿Cómo comparo dos URL?

Introduce o pega la primera URL en el lado Antes y la segunda en el lado Después, y luego carga y compara. DiffFind carga el contenido de cada dirección y muestra todas las diferencias entre ambos.

¿Puede DiffFind comparar el contenido que devuelven dos URL?

Sí. DiffFind carga el contenido de texto que devuelve cada URL, como una respuesta de API en JSON, XML o texto sin formato, y compara los dos resultados.

¿Cuál es la diferencia entre la comparación de URL y la de cURL?

La comparación de URL toma dos direcciones. La comparación de cURL toma dos comandos cURL completos, de modo que cada solicitud puede tener su propio método, encabezados y cuerpo. Usa la comparación de cURL cuando una solicitud necesite algo más que una dirección.

¿Puede la IA explicar los cambios relevantes entre URL?

De forma opcional. La comparación léxica exacta siempre va primero y funciona sin IA. Después puedes añadir el análisis semántico con IA para explicar qué significan los cambios.

¿Puedo comparar endpoints de staging y de producción?

Sí. Introduce la URL de staging en un lado y la de producción en el otro, y compara las respuestas.

Herramientas relacionadas

Para solicitudes completas, consulta Comparar API. Para comparar archivos en lugar de direcciones, prueba Comparar texto, la comparación de documentos de Word o la comparación de PDF.
